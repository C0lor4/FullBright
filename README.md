# Fullbright

![Fullbright icon](icon.png)

THE **END** OF NIGHT

Press **G** to toggle full brightness in BOTH single-player or multiplayer. Fullbright is on by default.

**Supporting Version:** Horizon 26.3 Nightly 2026-11-18 (`6d765e0`).

**Settings: Options > Mods > Fullbright > Config** 

**Shortcut: Options > Controls**.

#

天亮啦

按 **G** 切换全亮，单人和多人均可使用，默认开启。

适用于 Horizon 26.3 Nightly 2026-11-18（`dd67b76`）

**快捷键在 Options > Controls**

## Installation / 安装

```powershell
Set-Location '~\Fullbright'
py -3.11 .\package.py --install
```

## 中文说明

**天亮啦！**

在游戏中按 **G** 即可切换全亮模式，单人游戏和多人游戏均可使用。全亮模式默认开启。

**适配版本：** Horizon 26.3 Nightly 2026-11-18（`dd67b76`；该 Nightly 于 11 月 19 日发布）。

**设置：** Options > Mods > Fullbright > Config

**快捷键：** Options > Controls

### 安装与构建

在 Horizon 启动器的 Mods / Import 页面导入 `fullbright.hmod`，然后为所选配置构建 Native Mods 实例，并启动该 Native 实例。建议先移除旧版 Fullbright，避免旧源码与新版重复加载。

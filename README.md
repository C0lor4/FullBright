# Fullbright

THE **END** OF NIGHT

Press **G** to toggle full brightness in BOTH single-player or multiplayer. Fullbright is on by default.

**Supporting Version:** Horizon 26.3 Nightly 2026-11-18 (`6d765e0`).

**Settings: Options > Mods > Fullbright > Config** 

**Shortcut: Options > Controls**.

#

天亮啦

按 **G** 切换全亮，单人和多人均可使用，默认开启。

适用于 Horizon 26.3 Nightly 2026-11-18（`6d765e0`）

**设置在 Options > Mods > Fullbright > Config** 

**快捷键在 Options > Controls**

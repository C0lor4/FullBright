# Fullbright

![Fullbright icon](icon.png)

THE **END** OF NIGHT

Press **G** to toggle full brightness in BOTH single-player or multiplayer. Fullbright is on by default.

**Supporting Version:** Horizon 26.3 Nightly 2026-11-19（`f00125f`）
**Settings: Options > Mods > Fullbright > Config** 

**Shortcut: Options > Controls**.

#

**天亮啦！**

在游戏中按 **G** 即可切换全亮模式，单人游戏和多人游戏均可使用。全亮模式默认开启。

**适配版本：** Horizon 26.3 Nightly 2026-11-19（`f00125f`）

**设置：** Options > Mods > Fullbright > Config

**快捷键：** Options > Controls


## Installation / 安装

```powershell
Set-Location '~\Fullbright'
py -3.11 .\package.py --install
```

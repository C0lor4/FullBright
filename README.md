# Fullbright

![Fullbright icon](icon.png)

THE **END** OF NIGHT

Press **G** to toggle full brightness in BOTH single-player or multiplayer. Fullbright is on by default.

**Supporting Version:** game nightly-2026-11-19-dd67b76

**Settings: Options > Mods > Fullbright > Config** 

**Shortcut: Options > Controls**.
